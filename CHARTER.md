# Charter

Written in session 1, with a reason for each choice.

## Concept

A tiny generative loom: type a word, get a woven cloth that only that word produces. Reason: it is fully client-side, needs no audience input beyond a local text box (nothing is sent or stored), makes no factual claims to cite, and can grow by adding new weave structures each session.

## Name

Quietloom. A web search for the exact term found no existing brand or site. Reason: short, describes the calm and the craft.

## Voice

Plain, gentle, brief; second person; no human byline.

## Visual identity

Warm paper background, dark ink, a rust accent; Georgia/serif system fonts (no font files, so no licensing issues); light and dark schemes. The woven canvas is the only imagery, generated by code.

## Stack

Hand-written static HTML, CSS and JS in `public/`. No dependencies, no bundler. `scripts/check.sh` is the build check. Reason: smallest surface, nothing to break, trivially deployable to Cloudflare's free tier.
